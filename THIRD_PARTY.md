# Runtime and asset attribution

The browser runtime is **Pyodide 0.27.7**, distributed under the Mozilla Public
License 2.0. The unmodified runtime files were downloaded from:
https://cdn.jsdelivr.net/pyodide/v0.27.7/full/

Corresponding source code and build instructions:
https://github.com/pyodide/pyodide/tree/0.27.7

Its license is included as `runtime/LICENSE-PYODIDE.txt`.
The bundled CPython is version 3.12.7; its license and included third-party
notices are in `runtime/LICENSE-PYTHON.txt`. Source:
https://github.com/python/cpython/tree/v3.12.7

The runtime distribution's package information is retained in
`runtime/pyodide-lock.json`. No optional third-party Python packages are loaded.

The existing game's soundtrack and sound-effect credits are retained with the
assets in `assets/audio`. See those attribution documents and manifests for
individual authors, licenses, and sources. Typography uses Google Fonts Cinzel
and Inter, with system-font fallbacks.

## Generated curse sounds
Cursed Coin, Cursed Idol and Cursed Spoils were generated through the user’s Runway account with approval (one second each, three credits total). These are generated assets, not CC0 sound-library files.
